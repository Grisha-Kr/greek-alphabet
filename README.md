# Греческий: алфавит и слова. Карточки и тест

Интерактивные карточки для изучения греческого алфавита по главе 3 «Алфавит и произношение» учебника
У. Д. Маунса «Основы библейского греческого языка» (СПб, 2011, с. 23–27).

- **Карточки** — переворот касанием, режимы «буква → название» и «название → буква», перемешивание, отметки «знаю / повторить», набор «Трудные».
- **Тест** — название, буква или звук, 4 варианта ответа, разбор каждой ошибки.
- **Таблица** — весь алфавит и главное из главы.

## Слова

Переключатель «Алфавит / Слова» вверху открывает лексический минимум глав 4–36: 320 слов (`words.js`).

- **Карточки**: «греческое → русское» и обратно, выбор одной главы или глав с начала по выбранную. Режим «Повторение» работает по интервалам: 10 новых слов за сессию, «знаю» отодвигает слово на 1, 3, 7, 14, 30 и 60 дней, «повторить» возвращает его через три карточки и сбрасывает интервал. Есть наборы «Все» и «Трудные».
- **Тест**: перевод или греческое слово, 20 вопросов, 4 варианта. Неверные варианты подбираются из той же части речи. Ошибки попадают в «Трудные».
- **Словарь**: все слова по главам, поиск по-гречески (без учёта ударений и придыханий) и по-русски, частотность в НЗ, особые формы.

Прогресс сохраняется в браузере на этом устройстве, отдельно для алфавита и для слов.
